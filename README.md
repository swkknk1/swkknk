# 存货集市 · 个人私物出清与选购系统

一个专为个人搬家、闲置整理与好物出清打造的轻量级展示与选购清单网站。

无需依赖复杂的第三方电商平台，买家也无需注册繁琐账号，打开网页即可像逛集市一样浏览实物实况，挑选心仪物品并一键通过 Gmail 邮件或微信与店主预约交接。

---

## 💡 主要作用与功能

- **好物直观陈列**：支持按分类筛选（数码摄影、电脑外设、生活美学、图书手办等）、成色标注、实物实拍多图全方位展示。
- **免密极简挑选**：买家无需注册账号，点击卡片【我想买】即可自由勾选多件心仪物品；浏览器通过轻量 Cookie 免密记住买家称呼与邮箱，再次进站免重复输入。
- **一键直发店主**：
  - **网页版 Gmail 发送**：一键在新标签页打开 Gmail 并自动填入已选物品明细与合计总额，直发店主邮箱。
  - **微信扫码沟通**：一键将选购清单复制到剪贴板，并弹出店主微信名片二维码，买家扫码粘贴即可私信沟通或协商打包细节。
- **灵活自提/面交**：清晰展示交接地点与领取时段说明（如校内面交验货或同城自提）。
- **零成本纯静态部署**：无需购买和维护云服务器，构建出的静态网页可永久免费托管在 Netlify 等平台，打开速度极快且安全稳定。

---

## 🛠️ 常用命令

```bash
# 本地启动预览与管理
npm run dev

# 打包编译（将生成的 dist 文件夹上传到 Netlify 即可上线）
npm run build
```
